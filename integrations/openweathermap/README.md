# Интеграция: OpenWeatherMap — Погода в MimiSmart

PHP-скрипт для получения актуальных данных о погоде через [OpenWeatherMap API](https://openweathermap.org/api) и отображения их в виртуальных сенсорах приложения MimiSmart.

---

## Что делает скрипт

Запрашивает текущую погоду по координатам и передаёт следующие данные в MimiSmart:

| Данные | Сенсор |
|---|---|
| Дата, страна, город, давление (hPa) | `dev` — текстовый блок |
| Скорость ветра (м/с) | `dev2` |
| Влажность (%) | `dev3` |
| Ощущаемая температура (°C) | `dev4` |
| Температура (°C) | `dev5` |

---

## Получение API-ключа OpenWeatherMap

1. Зарегистрируйся на [openweathermap.org](https://openweathermap.org/)
2. Перейди в раздел **API keys** в личном кабинете
3. Создай новый ключ или используй ключ по умолчанию (`Default`)
4. Ключ активируется в течение нескольких минут после создания
5. Бесплатный план (`Free`) позволяет делать до **60 запросов в минуту** — для домашней автоматизации более чем достаточно

---

## Настройка в MimiSmart

Скрипт настраивается через интерфейс MimiSmart (скрипт с типом **"Проверка погоды"**, id скрипта: `524`).

### Поля настройки:

| Поле | Описание | Пример |
|---|---|---|
| **id of скрипта** | Номер скрипта в MimiSmart | `524` |
| **Укажите широту** | Широта местоположения | `59.948857` |
| **Укажите долготу** | Долгота местоположения | `30.366183` |
| **Укажите ключ API OpenWeather** | Ключ с сайта openweathermap.org | `716eaf121ec7bf44...` |
| **Укажите IP адрес шлюза** | IP шлюза, на котором висит CM-скрипт | `192.168.1.134` |
| **Интервал проверки** | Как часто обновлять погоду | по усмотрению |

> **Совет:** Скрипт лучше вешать на шлюз или виртуальную CM сервера 900.

## Конфигурация в коде

В файле `96.sh` при необходимости можно изменить:

```php
date_default_timezone_set("Asia/Ashgabat");  // Часовой пояс

define("HOST", "127.0.0.1");   // IP MimiSmart-сервера (локальный)
define("PORT", 55555);          // UDP-порт MimiSmart
define("SECRET_KEY", "");       // Ключ шифрования (если используется)
```
