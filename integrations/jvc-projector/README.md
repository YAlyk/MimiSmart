# Интеграция: Проектор JVC

Управление проектором JVC D-ILA через бинарные TCP-команды по локальной сети.

---

## Протокол

JVC D-ILA проекторы принимают команды управления через TCP-соединение на **порту 4661**.  
Команды передаются в виде **бинарных HEX-последовательностей**.

### Порядок подключения (стандартный, для новых моделей)

Часть моделей JVC требует предварительного «рукопожатия» перед отправкой команды:

1. Установить TCP-соединение (3-way handshake)
2. Проектор отвечает: `PJ_OK`
3. Клиент отправляет: `PJREQ`
4. Проектор отвечает: `PJACK`
5. Теперь можно отправлять команды

> Для **старых моделей JVC** (и некоторых прошивок) рукопожатие не требуется — команда отправляется напрямую. Скрипт `21.sh` использует именно этот упрощённый режим через `/dev/tcp`.

---

## Скрипты

### 21.sh — Включение проектора
```bash
./21.sh
```

Отправляет бинарную команду включения питания на проектор.

**Команда (HEX):**
```
06 14 00 04 00 34 11 01 00 5E C2
```

Использует bash-псевдоустройство `/dev/tcp/<ip>/<port>` для прямой отправки без дополнительных утилит.

---

## Конфигурация

В скрипте `21.sh`:
```bash
data='\x06\x14\x00\x04\x00\x34\x11\x01\x00\x5E\xC2'
ip="192.168.1.4"    # IP-адрес проектора
port="4661"         # TCP-порт (стандартный для JVC)
```

---

## Ручное тестирование

```bash
# Проверить доступность порта
nc -zv 192.168.1.4 4661

# Отправить команду включения
echo -n -e '\x06\x14\x00\x04\x00\x34\x11\x01\x00\x5E\xC2' > /dev/tcp/192.168.1.4/4661
```

---

## Примечание о совместимости

Структура HEX-команды и необходимость рукопожатия (`PJREQ/PJACK`) зависят от модели и года выпуска проектора. Если команда не выполняется:

1. Проверь, требует ли твоя модель рукопожатие
2. Убедись, что в настройках проектора включён **Network Standby** (сетевой режим ожидания)
3. Проверь IP-адрес: `Меню → Сеть → Сетевые настройки`
