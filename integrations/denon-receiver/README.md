# Интеграция: Ресивер Denon AVR

Управление AV-ресивером Denon через Telnet (порт 23) и PHP-скрипты.

---

## Протокол

Denon AVR принимает текстовые команды через Telnet на **порту 23**.  
Каждая команда — строка ASCII, заканчивающаяся символом `CR` (`\r`, 0x0D).  
Одновременно поддерживается только **одно подключение** на порту 23.

### Примеры команд

| Команда | Действие |
|---|---|
| `PWON` | Включить ресивер |
| `PWSTANDBY` | Перевести в режим ожидания |
| `SITV` | Выбрать источник TV |
| `SIGAME` | Выбрать источник Game |
| `SIMPLAY` | Выбрать источник Media Player |
| `PW?` | Запросить статус питания |
| `SI?` | Запросить текущий источник |

> После команды `PWON` необходимо выждать **~1 секунду** перед отправкой следующей команды.

## Скрипты

### 90.sh — Включение ресивера
```bash
./90.sh
```
Отправляет команду `PWON` через netcat на порт 23.

---

### 91.sh — Выключение ресивера
```bash
./91.sh
```
Отправляет команду `PWSTANDBY` через netcat.

---

### 92.sh — Источник: TV
```bash
./92.sh
```
Отправляет команду `SITV` — переключает вход на TV.

---

### 93.sh — Источник: Game
```bash
./93.sh
```
Отправляет команду `SIGAME` — переключает вход на Game.

---

### 94.sh — Источник: Media Player
```bash
./94.sh
```
Отправляет команду `SIMPLAY` — переключает вход на Media Player.

---

### 95.sh — Отправка команды через GNU screen (PHP)
```bash
./95.sh <arg1> <arg2> <hex_command>
```
PHP-скрипт, запускается из MimiSmart.  
Принимает HEX-строку команды (аргумент 3) и передаёт её в активную `screen`-сессию `Denon` через `stuff`.

**Требования:**
- PHP CLI
- Запущенная `screen`-сессия с именем `Denon`, подключённая к ресиверу по Telnet
- Для создания сессии: `screen -S Denon telnet 192.168.1.12 23`

## Конфигурация

В Bash-скриптах (90–94):
```bash
IP="192.168.1.12"   # IP-адрес ресивера Denon в вашей сети
```

---

## Ручное тестирование

```bash
# Включить ресивер
echo "PWON" | nc -w 2 192.168.1.12 23

# Проверить статус
echo "PW?" | nc -w 2 192.168.1.12 23

# Выключить
echo "PWSTANDBY" | nc -w 2 192.168.1.12 23
```
