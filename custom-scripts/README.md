# Custom Scripts — Кастомные скрипты

Коллекция скриптов на языке Mimi Logic C-подобного DSL, написанных под конкретные объекты и технические задания.  
Каждый скрипт содержит встроенный JSON-манифест (`desc`, `vars`) для подключения через web интерфейс.

## Примечания

- Все скрипты подключаются через раздел **Скрипты** в web интерфейсе.
- Параметры конфигурации (устройства, IP, пороги) задаются через переменные в JSON-манифесте скрипта — без редактирования кода.
- Скрипты, в названии которых есть название объекта, содержат захардкоженные адреса или специфичную логику под это ТЗ — перед переносом на другой объект требуют адаптации.
